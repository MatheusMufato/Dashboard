# 📊 Dashboard Desktop

Aplicação desktop em Python com interface moderna em CustomTkinter, tema escuro e navegação entre telas.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

</div>

## ✨ Destaques

- Tela de login
- Dashboard principal
- Perfil, calendário, aulas e registro pessoal

## 🚀 Como rodar

```bash
pip install customtkinter
python App.py
```
